# Third-party sources for Pinwheel for Windows

The source of the third-party components Pinwheel for Windows ships under copyleft licences (the bundled FFmpeg and every library built into it; the LGPL libraries Magick.Native links statically), uploaded by scripts/publish-source-mirror.sh as the assets of one release per Pinwheel version. Nothing else is uploaded: the script refuses any file not listed here, or whose size or SHA-256 differs.

Pinwheel 0.1.0: release [`pinwheel-0.1.0`](https://github.com/Emin-Emini/pinwheel-third-party-sources/releases/tag/pinwheel-0.1.0). Each release holds the sources of the components that Pinwheel version ships; nothing here is Pinwheel's own code.

The licence column names each component's main licence as its project states it; the licence files inside each archive (reproduced in Pinwheel's THIRD-PARTY-NOTICES.txt and licenses folder) are authoritative.

## FFmpeg n9.0.2-48-gd4070a14ce, as Pinwheel bundles it (ffmpeg.exe, ffprobe.exe and the av*/sw* DLLs in the ffmpeg folder)

FFmpeg-Builds' win64 "lgpl-shared" variant (release autobuild-2026-11-07-12-47, recipe c63bb308a1), unmodified. Every library is built from the archive listed here and linked statically into the FFmpeg DLLs; the archives were made by Pinwheel's scripts/ffmpeg/mirror-sources.py from the recipe's pinned revisions. libopenh264 is built in too, but Pinwheel never uses it.

**Relinking.** Pinwheel runs ffmpeg.exe and ffprobe.exe as separate programs. To use a modified FFmpeg, or FFmpeg with modified libraries, build it with the recipe (or any LGPL build with the same encoders) and replace the contents of the ffmpeg folder in Pinwheel's install folder (%LOCALAPPDATA%\Programs\Pinwheel\ffmpeg).
